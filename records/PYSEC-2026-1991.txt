PYSEC-2026-1991 PyPI/trytond — trytond does not enforce access rights for the route of the HTML editor.
package: trytond
ecosystem: PyPI
versions affected:
  >= 6.0.0, < 6.0.70, >= 7.0.0, < 7.0.40, >= 7.1.0, < 7.4.21, >= 7.5.0, < 7.6.11 (ECOSYSTEM)

Tryton trytond 6.0 before 7.6.11 does not enforce access rights for the route of the HTML editor. This is fixed in 7.6.11, 7.4.21, 7.0.40, and 6.0.70.
