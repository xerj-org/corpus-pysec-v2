PYSEC-2021-105 PyPI/ansible — A flaw was found in the use of insufficiently random values in Ansible. Two random password lookups 
package: ansible
ecosystem: PyPI
versions affected:
  >= 0, < 2.9.6 (ECOSYSTEM)
aliases: CVE-2020-10729, GHSA-r6h7-5pq2-j77h
references:
  https://github.com/ansible/ansible/issues/34144
  https://bugzilla.redhat.com/show_bug.cgi?id=1831089
  https://github.com/advisories/GHSA-r6h7-5pq2-j77h

A flaw was found in the use of insufficiently random values in Ansible. Two random password lookups of the same length generate the equal value as the template caching action for the same file since no re-evaluation happens. The highest threat from this vulnerability would be that all passwords are exposed at once for the file. This flaw affects Ansible Engine versions before 2.9.6.
