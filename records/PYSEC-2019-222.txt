PYSEC-2019-222 PyPI/tensorflow-cpu — Invalid memory access and/or a heap buffer overflow in the TensorFlow XLA compiler in Google TensorF
package: tensorflow-cpu
ecosystem: PyPI
versions affected:
  >= 0, < 1.7.1 (ECOSYSTEM)
aliases: CVE-2018-10055
references:
  https://github.com/tensorflow/tensorflow/blob/master/tensorflow/security/advisory/tfsa-2018-006.md

Invalid memory access and/or a heap buffer overflow in the TensorFlow XLA compiler in Google TensorFlow before 1.7.1 could cause a crash or read from other parts of process memory via a crafted configuration file.
