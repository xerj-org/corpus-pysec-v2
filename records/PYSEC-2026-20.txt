PYSEC-2026-20 PyPI/apache-airflow — Dag Authors, who normally should not be able to execute code in the webserver context could craft XC
package: apache-airflow
ecosystem: PyPI
versions affected:
  >= 3.1.8, < 3.2.0 (ECOSYSTEM)
aliases: CVE-2026-33858, GHSA-mc4f-r875-v87w
references:
  http://www.openwall.com/lists/oss-security/2026/04/13/7
  https://lists.apache.org/thread/1npt3o2x81s0gw9tmfcv4n7p1z9hdmy0
  https://github.com/apache/airflow/pull/64148
  https://github.com/advisories/GHSA-mc4f-r875-v87w

Dag Authors, who normally should not be able to execute code in the webserver context could craft XCom payload causing the webserver to execute arbitrary code. Since Dag Authors are already highly trusted, severity of this issue is Low.


Users are recommended to upgrade to Apache Airflow 3.2.0, which resolves this issue.
