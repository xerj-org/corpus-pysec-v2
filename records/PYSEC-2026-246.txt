PYSEC-2026-246 PyPI/picklescan — picklescan before 0.0.30 fails to detect malicious pickle files using idlelib.pyshell.ModifiedInterp
package: picklescan
ecosystem: PyPI
versions affected:
  >= 0, < 0.0.30 (ECOSYSTEM)
aliases: CVE-2025-71357, GHSA-j343-8v2j-ff7w
references:
  https://www.vulncheck.com/advisories/picklescan-arbitrary-code-execution-via-undetected-idlelib-pyshell-modifiedinterpreter-runcommand
  https://github.com/mmaitre314/picklescan/security/advisories/GHSA-j343-8v2j-ff7w

picklescan before 0.0.30 fails to detect malicious pickle files using idlelib.pyshell.ModifiedInterpreter.runcommand in reduce methods. Attackers can embed undetected code in pickle files that executes remote commands when loaded by victims.
