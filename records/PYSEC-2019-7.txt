PYSEC-2019-7 PyPI/buildbot — www/resource.py in Buildbot before 1.8.1 allows CRLF injection in the Location header of /auth/login
package: buildbot
ecosystem: PyPI
versions affected:
  >= 0.9.0, < 1.8.1 (ECOSYSTEM)
aliases: CVE-2019-7313, GHSA-66x7-2r56-fj77
references:
  https://github.com/buildbot/buildbot/wiki/CRLF-injection-in-Buildbot-login-and-logout-redirect-code
  https://github.com/advisories/GHSA-66x7-2r56-fj77

www/resource.py in Buildbot before 1.8.1 allows CRLF injection in the Location header of /auth/login and /auth/logout via the redirect parameter. This affects other web sites in the same domain.
