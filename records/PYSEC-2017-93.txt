PYSEC-2017-93 PyPI/priority — A HTTP/2 implementation built using any version of the Python priority library prior to version 1.2.
package: priority
ecosystem: PyPI
versions affected:
  >= 0, < 1.2.0 (ECOSYSTEM)
aliases: CVE-2016-6580, GHSA-h3q4-6j7f-r24c
references:
  https://python-hyper.org/priority/en/latest/security/CVE-2016-6580.html
  http://www.securityfocus.com/bid/92311
  https://github.com/advisories/GHSA-h3q4-6j7f-r24c

A HTTP/2 implementation built using any version of the Python priority library prior to version 1.2.0 could be targeted by a malicious peer by having that peer assign priority information for every possible HTTP/2 stream ID. The priority tree would happily continue to store the priority information for each stream, and would therefore allocate unbounded amounts of memory. Attempting to actually use a tree like this would also cause extremely high CPU usage to maintain the tree.
