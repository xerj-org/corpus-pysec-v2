PYSEC-2017-38 PyPI/salt — When using the local_batch client from salt-api in SaltStack Salt before 2015.8.13, 2016.3.x before 
package: salt
ecosystem: PyPI
versions affected:
  >= 0, < 2015.8.13, >= 2016.3, < 2016.3.5, >= 2016.11, < 2016.11.2 (ECOSYSTEM)
aliases: CVE-2017-5192, GHSA-f2h7-4f84-8qrm
references:
  https://docs.saltstack.com/en/latest/topics/releases/2016.11.2.html
  https://docs.saltstack.com/en/2016.3/topics/releases/2016.3.5.html
  https://docs.saltstack.com/en/2016.3/topics/releases/2015.8.13.html
  https://github.com/advisories/GHSA-f2h7-4f84-8qrm

When using the local_batch client from salt-api in SaltStack Salt before 2015.8.13, 2016.3.x before 2016.3.5, and 2016.11.x before 2016.11.2, external authentication is not respected, enabling all authentication to be bypassed.
