PYSEC-2017-26 PyPI/pysaml2 — Python package pysaml2 version 4.4.0 and earlier reuses the initialization vector across encryptions
package: pysaml2
ecosystem: PyPI
versions affected:
  >= 0, < 4.6.0 (ECOSYSTEM)
aliases: CVE-2017-1000246, GHSA-cq94-qf6q-mf2h
references:
  https://github.com/rohe/pysaml2/issues/417
  https://github.com/advisories/GHSA-cq94-qf6q-mf2h

Python package pysaml2 version 4.4.0 and earlier reuses the initialization vector across encryptions in the IDP server, resulting in weak encryption of data.
