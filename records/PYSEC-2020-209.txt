PYSEC-2020-209 PyPI/ansible — A flaw was found in the Ansible Engine, in ansible-engine 2.8.x before 2.8.15 and ansible-engine 2.9
package: ansible
ecosystem: PyPI
versions affected:
  >= 2.8.0, < 2.8.16rc1, >= 2.9.0, < 2.9.14rc1 (ECOSYSTEM)
aliases: CVE-2020-14365, GHSA-m429-fhmv-c6q2
references:
  https://bugzilla.redhat.com/show_bug.cgi?id=1869154
  https://github.com/advisories/GHSA-m429-fhmv-c6q2

A flaw was found in the Ansible Engine, in ansible-engine 2.8.x before 2.8.15 and ansible-engine 2.9.x before 2.9.13, when installing packages using the dnf module. GPG signatures are ignored during installation even when disable_gpg_check is set to False, which is the default behavior. This flaw leads to malicious packages being installed on the system and arbitrary code executed via package installation scripts. The highest threat from this vulnerability is to integrity and system availability.
