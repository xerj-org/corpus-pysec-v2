PYSEC-2020-252 PyPI/scalyr-agent-2 — The Scalyr Agent before 2.1.10 has Missing SSL Certificate Validation because, in some circumstances
package: scalyr-agent-2
ecosystem: PyPI
versions affected:
  >= 0, < 2.1.10 (ECOSYSTEM)
aliases: CVE-2020-24715, GHSA-738x-v49g-p6hx

The Scalyr Agent before 2.1.10 has Missing SSL Certificate Validation because, in some circumstances, native Python code is used that lacks a comparison of the hostname to commonName and subjectAltName.
