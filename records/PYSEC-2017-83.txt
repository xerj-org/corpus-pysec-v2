PYSEC-2017-83 PyPI/scrapy — Scrapy 1.4 allows remote attackers to cause a denial of service (memory consumption) via large files
package: scrapy
ecosystem: PyPI
versions affected:
  >= 0.7 (ECOSYSTEM)
aliases: CVE-2017-14158, GHSA-h7wm-ph43-c39p
references:
  https://github.com/scrapy/scrapy/issues/482
  http://blog.csdn.net/wangtua/article/details/75228728
  https://github.com/advisories/GHSA-h7wm-ph43-c39p

Scrapy 1.4 allows remote attackers to cause a denial of service (memory consumption) via large files because arbitrarily many files are read into memory, which is especially problematic if the files are then individually written in a separate thread to a slow storage resource, as demonstrated by interaction between dataReceived (in core/downloader/handlers/http11.py) and S3FilesStore.
