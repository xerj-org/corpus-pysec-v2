PYSEC-2014-97 PyPI/apache-libcloud — Libcloud 0.12.3 through 0.13.2 does not set the scrub_data parameter for the destroy DigitalOcean AP
package: apache-libcloud
ecosystem: PyPI
versions affected:
  >= 0.12.3, < 0.13.3 (ECOSYSTEM)
aliases: CVE-2013-6480, GHSA-g892-9h8m-r69r
references:

Libcloud 0.12.3 through 0.13.2 does not set the scrub_data parameter for the destroy DigitalOcean API, which allows local users to obtain sensitive information by leveraging a new VM.
