  >= 0, < 0.3.2 (ECOSYSTEM)
aliases: CVE-2016-3691, GHSA-799h-qr84-pcrp

Routes in Kallithea before 0.3.2 allows remote attackers to bypass the CSRF protection by using the GET HTTP request method.
