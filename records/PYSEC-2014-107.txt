PYSEC-2014-107 PyPI/keystone — The MySQL token driver in OpenStack Identity (Keystone) 2014.1.x before 2014.1.2.1 and Juno before J
package: keystone
ecosystem: PyPI
versions affected:
  >= 0, < 8.0.0a0 (ECOSYSTEM)
aliases: CVE-2014-5251, GHSA-gmvp-5rf9-mxcm
references:
  https://bugs.launchpad.net/keystone/+bug/1347961

  http://rhn.redhat.com/errata/RHSA-2014-1121.html

The MySQL token driver in OpenStack Identity (Keystone) 2014.1.x before 2014.1.2.1 and Juno before Juno-3 stores timestamps with the incorrect precision, which causes the expiration comparison for tokens to fail and allows remote authenticated users to retain access via an expired token.
