PYSEC-2026-2101 PyPI/aiohttp — AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python. Prior to version 3.1
package: aiohttp
ecosystem: PyPI
versions affected:
  >= 0, < 3.13.4 (ECOSYSTEM)
aliases: CVE-2026-34519, GHSA-mwh4-6h8g-pg8w
references:
  https://github.com/aio-libs/aiohttp/releases/tag/v3.13.4
  https://github.com/aio-libs/aiohttp/commit/53b35a2f8869c37a133e60bf1a82a1c01642ba2b
  https://github.com/aio-libs/aiohttp/security/advisories/GHSA-mwh4-6h8g-pg8w

AIOHTTP is an asynchronous HTTP client/server framework for asyncio and Python. Prior to version 3.13.4, an attacker who controls the reason parameter when creating a Response may be able to inject extra headers or similar exploits. This issue has been patched in version 3.13.4.
