PYSEC-2026-751 PyPI/swift — Temporary urls leaked via logging
package: swift
ecosystem: PyPI
versions affected:
  >= 0, < 2.15.2 (ECOSYSTEM)
aliases: CVE-2017-8761, GHSA-8fxc-qm65-vpxg
references:
  https://nvd.nist.gov/vuln/detail/CVE-2017-8761
  https://bugs.launchpad.net/swift/+bug/1685798/comments/18
  https://launchpad.net/bugs/1685798
  https://pypi.org/project/swift
  https://github.com/advisories/GHSA-8fxc-qm65-vpxg

In OpenStack Swift prior to 2.15.2, the proxy-server logs full tempurl paths, potentially leaking reusable tempurl signatures to anyone with read access to these logs. All Swift deployments using the tempurl middleware are affected.
