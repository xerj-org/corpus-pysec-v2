PYSEC-2026-13 PyPI/apache-airflow — Dag Authors, who normally should not be able to execute code in the webserver context could craft XC
package: apache-airflow
ecosystem: PyPI
versions affected:
  >= 0, < 3.2.0 (ECOSYSTEM)
aliases: CVE-2026-25917
references:
  http://www.openwall.com/lists/oss-security/2026/04/17/9
  https://lists.apache.org/thread/6whgpkqbh12rvpfmvcg8b0vwlv4hq3po
  https://github.com/apache/airflow/pull/61641

Dag Authors, who normally should not be able to execute code in the webserver context could craft XCom payload causing the webserver to execute arbitrary code. Since Dag Authors are already highly trusted, severity of this issue is Low.

Users are recommended to upgrade to Apache Airflow 3.2.0, which fixes the issue.
