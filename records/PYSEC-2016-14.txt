PYSEC-2016-14 PyPI/django — Django 1.9.x before 1.9.2, when ModelAdmin.save_as is set to True, allows remote authenticated users
package: django
ecosystem: PyPI
versions affected:
  >= 1.9, < 1.9.2 (ECOSYSTEM)
aliases: CVE-2016-2048, GHSA-46x4-9jmv-jc8p
references:
  http://www.securitytracker.com/id/1034894
  https://www.djangoproject.com/weblog/2016/feb/01/releases-192-and-189/
  http://www.securityfocus.com/bid/82329
  https://github.com/advisories/GHSA-46x4-9jmv-jc8p

Django 1.9.x before 1.9.2, when ModelAdmin.save_as is set to True, allows remote authenticated users to bypass intended access restrictions and create ModelAdmin objects via the "Save as New" option when editing objects and leveraging the "change" permission.
