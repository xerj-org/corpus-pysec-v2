PYSEC-2020-13 PyPI/ansible — A flaw was found in the Ansible Engine affecting Ansible Engine versions 2.7.x before 2.7.17 and 2.8
package: ansible
ecosystem: PyPI
versions affected:
  >= 2.7.0, < 2.7.17, >= 2.8.0, < 2.8.11, >= 2.9.0, < 2.9.7 (ECOSYSTEM)
aliases: CVE-2020-1746, GHSA-j2h6-73x8-22c4
references:
  https://github.com/ansible/ansible/pull/67866

  https://github.com/advisories/GHSA-j2h6-73x8-22c4

A flaw was found in the Ansible Engine affecting Ansible Engine versions 2.7.x before 2.7.17 and 2.8.x before 2.8.11 and 2.9.x before 2.9.7 as well as Ansible Tower before and including versions 3.4.5 and 3.5.5 and 3.6.3 when the ldap_attr and ldap_entry community modules are used. The issue discloses the LDAP bind password to stdout or a log file if a playbook task is written using the bind_pw in the parameters field. The highest threat from this vulnerability is data confidentiality.
