PYSEC-2026-1064 PyPI/web2py — Open redirect in web2py
package: web2py
ecosystem: PyPI
versions affected:
  >= 0, < 2.23.1 (ECOSYSTEM)
aliases: CVE-2023-22432, GHSA-w4r7-vm83-q2c7
references:
  https://nvd.nist.gov/vuln/detail/CVE-2023-22432
  https://jvn.jp/en/jp/JVN78253670
  http://web2py.com
  http://web2py.com/init/default/download
  https://pypi.org/project/web2py
  https://github.com/advisories/GHSA-w4r7-vm83-q2c7

Open redirect vulnerability exists in web2py versions prior to 2.23.1. When using the tool, a web2py user may be redirected to an arbitrary website by accessing a specially crafted URL. As a result, the user may become a victim of a phishing attack.
