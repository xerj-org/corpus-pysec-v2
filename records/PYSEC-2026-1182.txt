PYSEC-2026-1182 PyPI/apache-superset — Apache Superset Open Redirect vulnerability
package: apache-superset
ecosystem: PyPI
versions affected:
  >= 0, < 3.0.0 (ECOSYSTEM)
aliases: CVE-2023-42502, GHSA-hc74-9vjm-c9xv
references:
  https://nvd.nist.gov/vuln/detail/CVE-2023-42502
  https://github.com/apache/superset

  https://pypi.org/project/apache-superset
  https://github.com/advisories/GHSA-hc74-9vjm-c9xv

An authenticated attacker with update datasets permission could change a dataset link to an untrusted site by spoofing the HTTP Host header, users could be redirected to this site when clicking on that specific dataset. This issue affects Apache Superset versions before 3.0.0.
