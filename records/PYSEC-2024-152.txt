PYSEC-2024-152 PyPI/aiocpa — aiocpa 0.1.13 contains credential harvesting code
package: aiocpa
ecosystem: PyPI
versions affected:
  0.1.13, 0.1.14
references:
  https://inspector.pypi.io/project/aiocpa/0.1.13/packages/ab/98/7343281068a2c39086d0b877219668a487508197f46e89b3f41046a4a8ba/aiocpa-0.1.13.tar.gz/aiocpa-0.1.13/cryptopay/utils/sync.py#line.44
  https://blog.pypi.org/posts/2024-11-25-aiocpa-attack-analysis/

aiocpa is a user-facing library for generating color gradients of text.
Version 0.1.13 introduced obfuscated, malicious code targeting
Crypto Pay users, forwarding client credentials to a remote Telegram bot.
All versions have been removed from PyPI.
