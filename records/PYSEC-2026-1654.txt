PYSEC-2026-1654 PyPI/mlflow — MLFlow unsafe deserialization
package: mlflow
ecosystem: PyPI
versions affected:
  >= 2.0.0rc0, <= 2.14.1 (ECOSYSTEM)
aliases: CVE-2024-37057, GHSA-j8mg-pqc5-x9gj
references:
  https://nvd.nist.gov/vuln/detail/CVE-2024-37057
  https://github.com/mlflow/mlflow
  https://hiddenlayer.com/sai-security-advisory/mlflow-june2024
  https://pypi.org/project/mlflow
  https://github.com/advisories/GHSA-j8mg-pqc5-x9gj

Deserialization of untrusted data can occur in versions of the MLflow platform running version 2.0.0rc0 or newer, enabling a maliciously uploaded Tensorflow model to run arbitrary code on an end user’s system when interacted with.
