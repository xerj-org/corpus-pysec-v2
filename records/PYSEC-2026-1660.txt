PYSEC-2026-1660 PyPI/mlflow — MLFlow unsafe deserialization
package: mlflow
ecosystem: PyPI
versions affected:
  >= 0.5.0, <= 3.4.0 (ECOSYSTEM)
aliases: CVE-2024-37059, GHSA-wf7f-8fxf-xfxc
references:
  https://nvd.nist.gov/vuln/detail/CVE-2024-37059
  https://github.com/mlflow/mlflow
  https://hiddenlayer.com/sai-security-advisory/mlflow-june2024
  https://pypi.org/project/mlflow
  https://github.com/advisories/GHSA-wf7f-8fxf-xfxc

Deserialization of untrusted data can occur in versions of the MLflow platform running version 0.5.0 or newer, enabling a maliciously uploaded PyTorch model to run arbitrary code on an end user’s system when interacted with.
