PYSEC-2021-848 PyPI/sockeye — Sockeye is an open-source sequence-to-sequence framework for Neural Machine Translation built on PyT
package: sockeye
ecosystem: PyPI
versions affected:
  >= 0, < 2.3.24 (ECOSYSTEM)
aliases: CVE-2021-43811, GHSA-ggmr-44cv-24pm
references:

  https://github.com/awslabs/sockeye/pull/964

Sockeye is an open-source sequence-to-sequence framework for Neural Machine Translation built on PyTorch. Sockeye uses YAML to store model and data configurations on disk. Versions below 2.3.24 use unsafe YAML loading, which can be made to execute arbitrary code embedded in config files. An attacker can add malicious code to the config file of a trained model and attempt to convince users to download and run it. If users run the model, the embedded code will run locally. The issue is fixed in version 2.3.24.
