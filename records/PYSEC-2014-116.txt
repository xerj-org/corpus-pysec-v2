PYSEC-2014-116 PyPI/swift — The TempURL middleware in OpenStack Object Storage (Swift) 1.4.6 through 1.8.0, 1.9.0 through 1.10.0
package: swift
ecosystem: PyPI
versions affected:
  >= 1.4.6, < 1.12.0 (ECOSYSTEM)
aliases: CVE-2014-0006, GHSA-cf9m-q836-vf26
references:
  https://bugs.launchpad.net/swift/+bug/1265665
  http://www.openwall.com/lists/oss-security/2014/01/17/5
  http://rhn.redhat.com/errata/RHSA-2014-0232.html

The TempURL middleware in OpenStack Object Storage (Swift) 1.4.6 through 1.8.0, 1.9.0 through 1.10.0, and 1.11.0 allows remote attackers to obtain secret URLs by leveraging an object name and a timing side-channel attack.
