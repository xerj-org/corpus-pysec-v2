PYSEC-2026-1465 PyPI/intel-tensorflow-avx512 — Authenticated Local Privilege Escalation vulnerability in Intel Optimization for Tensorflow
package: intel-tensorflow-avx512
ecosystem: PyPI
versions affected:
  >= 0, < 2.12 (ECOSYSTEM)
aliases: CVE-2023-27506, GHSA-m2f8-v8q4-3m59
references:
  https://nvd.nist.gov/vuln/detail/CVE-2023-27506

  https://github.com/advisories/GHSA-m2f8-v8q4-3m59

Improper buffer restrictions in the Intel(R) Optimization for Tensorflow software before version 2.12 may allow an authenticated user to potentially enable escalation of privilege via local access.
