PYSEC-2026-1643 PyPI/mlflow — MLFlow unsafe deserialization
package: mlflow
ecosystem: PyPI
versions affected:
  >= 1.1.0, <= 2.14.1 (ECOSYSTEM)
aliases: CVE-2024-37052, GHSA-76cg-cfhx-373f
references:
  https://nvd.nist.gov/vuln/detail/CVE-2024-37052
  https://github.com/mlflow/mlflow
  https://hiddenlayer.com/sai-security-advisory/mlflow-june2024
  https://pypi.org/project/mlflow
  https://github.com/advisories/GHSA-76cg-cfhx-373f

Deserialization of untrusted data can occur in versions of the MLflow platform running version 1.1.0 or newer, enabling a maliciously uploaded scikit-learn model to run arbitrary code on an end user’s system when interacted with.
