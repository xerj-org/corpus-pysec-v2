PYSEC-2020-151 PyPI/uvicorn — Uvicorn before 0.11.7 is vulnerable to HTTP response splitting. CRLF sequences are not escaped in th
package: uvicorn
ecosystem: PyPI
versions affected:
  >= 0, < 0.11.7 (ECOSYSTEM)
aliases: CVE-2020-7695, SNYK-PYTHON-UVICORN-570471, GHSA-f97h-2pfx-f59f
references:
  https://snyk.io/vuln/SNYK-PYTHON-UVICORN-570471

  https://github.com/advisories/GHSA-f97h-2pfx-f59f

Uvicorn before 0.11.7 is vulnerable to HTTP response splitting. CRLF sequences are not escaped in the value of HTTP headers. Attackers can exploit this to add arbitrary headers to HTTP responses, or even return an arbitrary response body, whenever crafted input is used to construct HTTP headers.
